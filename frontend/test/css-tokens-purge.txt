Dead global tokens, derived after Phase 2 steps 1 to 7
=======================================================

A global token is a custom property declared in app/styles/tokens.css. It is
referenced when its exact name (followed by a non-name character) appears
anywhere under frontend/ outside node_modules, .next, out and test/, or under
brand/: every stylesheet (a token used only inside another token's value is
live as long as that token is), every .ts/.tsx/.js/.mjs (inline styles,
setProperty, getPropertyValue), and public/*.html. games.css and revolt.css
count as referrers: the routes are hidden, not deleted. A token whose only
referrer is deleted is re-checked until nothing changes.
